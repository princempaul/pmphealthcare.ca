# Security Policy

This repository contains the static front end for the PMP Healthcare website
(https://pmphealthcare.ca). It is served as-is from the `main` branch.

## Supported versions

The site is not versioned. Only the current `main` branch is maintained and
receives security fixes.

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's
[private vulnerability reporting](https://github.com/princempaul/pmphealthcare.ca/security/advisories/new)
rather than opening a public issue.

When you report, please include:

- A description of the issue and the page or file affected
- Steps to reproduce it
- The potential impact, if you know it

**Do not include patient information or personal health information in a
report.** This repository contains none, and none should be sent.

## What to expect

- We aim to acknowledge reports within a few business days.
- If the report is accepted, we will fix it and credit you if you wish.
- If it is declined, we will explain why.
